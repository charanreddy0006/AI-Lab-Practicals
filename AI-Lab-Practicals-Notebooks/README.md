# AI Lab Practicals — Jupyter Notebooks

A structured set of 12 Python notebooks aligned with the Artificial Intelligence (01AI0511) practical list.

## Notebooks

1. Python setup and intelligent agents
2. BFS, DFS and Uniform-Cost Search
3. A* heuristic search and grid path planning
4. Minimax and alpha-beta pruning (Tic-Tac-Toe)
5. Rule-based expert system
6. Constraint satisfaction: map coloring and N-Queens
7. Bayesian network and probabilistic inference
8. Mini AI text-classification application
9. STRIPS-style planning
10. Value iteration in a grid-world
11. Propositional logic and first-order logic inference
12. k-NN, decision tree, Gaussian Naive Bayes and perceptron

## Requirements

- Python 3.9+
- Jupyter Notebook or JupyterLab

Most notebooks use only the Python standard library. No external machine-learning package is required.

## Run

```bash
python -m pip install notebook
jupyter notebook
```

Open a notebook and use **Run All**.

## Notes

- The notebooks are educational implementations intended to demonstrate core ideas.
- Practical 5 and Practical 8 use small illustrative rule-based examples; they are not production systems.
- Practical 7 uses illustrative conditional probability values.
